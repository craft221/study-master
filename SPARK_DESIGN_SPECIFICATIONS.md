## 🎯 VUE D'ENSEMBLE

### Concept
**Spark** est un écureuil énergique et travailleur qui accompagne les étudiants dans leur parcours d'apprentissage. Il symbolise :
- **L'accumulation de connaissances** (comme un écureuil stocke des noisettes)
- **L'énergie et la vivacité d'esprit** (étincelles = sparks)
- **La préparation** (stock pour l'hiver = préparation aux examens)
- **La persévérance et le travail régulier**

### Public Cible
- Étudiants universitaires et lycéens (16-25 ans)
- Professionnels en formation continue
- Design **ni trop enfantin, ni trop sérieux**

### Différenciation
- **vs Duolingo (Duo le hibou)** : Plus énergique, moins culpabilisant
- **vs Khan Academy** : Apporte de l'émotion et de l'engagement
- **Style** : Kawaii moderne, mais mature

## 🎭 PERSONNALITÉ ET TONALITÉ

### Traits de Personnalité
✅ **Énergique** - Toujours en mouvement, motivé
✅ **Encourageant** - Positif sans être condescendant
✅ **Travailleur** - Modèle de persévérance
✅ **Empathique** - Comprend les difficultés
✅ **Espiègle** - Un peu taquin pour motiver
✅ **Pédagogue** - Aide à comprendre sans donner les réponses

```
✅ BON : "7 jours de série ! Ton stock grandit ! Continue comme ça ! ⚡"
❌ MAUVAIS : "Bravo mon petit chou ! Tu es le meilleur du monde entier !"

✅ BON : "Cette noisette était amère... Mais on apprend de nos erreurs ! 💪"

✅ BON : "Mmm, cette note sent bon ! Je la range dans ma réserve ! 📚"
❌ MAUVAIS : "Note créée avec succès."
```

## 🎨 DESIGN VISUEL

### Palette de Couleurs

**Couleur Principale : Orange Écureuil**
- `#FF8C42` - Orange vif (fourrure principale)
- `#FFA500` - Orange doré (accents)
- `#FFFFFF` - Blanc (ventre, joues)
- `#8B4513` - Marron (contours, détails)

**Couleurs Secondaires (Étincelles)**
- `#FFD700` - Or (étincelles, noisettes magiques)
- `#FFFF00` - Jaune vif (éclairs d'énergie)
- `#FFC300` - Jaune doré (aura d'excitation)

**Couleurs d'État**
- Heureux : Orange vif
- Excité : Orange + étincelles dorées
- Triste : Orange délavé + bleu
- Pensif : Orange + violet/pourpre
- Endormi : Gris-beige

### Proportions Anatomiques

```
Tête : 40% de la hauteur totale
Corps : 35% de la hauteur totale
Queue : 50% de la hauteur totale (peut dépasser)

Yeux : Grands et expressifs (style kawaii)
  - Brillants avec reflet blanc
  - Position : haut de la tête
  - Forme : ovales arrondis

Oreilles : Pointues, petites, avec touffes de poils

Queue : TRÈS IMPORTANTE
  - Touffue et expressive
  - Peut être en forme de flamme/éclair
  - Utilisée pour exprimer l'émotion
```

### Style Graphique

**Option A : Illustration 2D Plate (Recommandé)**
- Style moderne flat design
- Contours nets, arrondis
- Ombres portées subtiles
- Compatible SVG (scalable)

**Option B : Illustration 3D Stylisée**
- Rendu cartoon 3D
- Textures simples
- Éclairage doux

**Option C : Pixel Art Moderne**
- Pour un style rétro-gaming
- Haute résolution (128x128 minimum)

### Éléments Obligatoires
1. **Noisette** - Toujours présente (dans les mains ou à côté)
2. **Étincelles** - Autour de Spark lors d'animations spéciales
3. **Expressions faciales** - Très expressives (sourcils, bouche, yeux)
4. **Queue volumineuse** - Élément signature

## 😊 ÉTATS ÉMOTIONNELS

### 1. HAPPY (Heureux) 😊
**Utilisation** : État par défaut, messages positifs
```
- Sourire doux
- Yeux ouverts, brillants
- Queue légèrement enroulée
- Tient une noisette
- Posture détendue
```

### 2. EXCITED (Excité) 🤩
**Utilisation** : Succès, achievements, nouveaux déblocages
```
- Grand sourire avec dents visibles
- Yeux étincelants (étoiles)
- Queue dressée en forme d'éclair
- Étincelles dorées autour
- Posture dynamique (saut)
- Noisette brillante/dorée
```

### 3. SAD (Triste) 😢
**Utilisation** : Échec à un quiz, inactivité prolongée
```
- Petite moue
- Yeux légèrement fermés ou larmes
- Queue basse, pendante
- Noisette cassée dans les mains
- Couleurs légèrement désaturées
- Posture affaissée
```

### 4. THINKING (Pensif) 🤔
**Utilisation** : Génération IA en cours, indices
```
- Main sur le menton (ou patte)
- Regard vers le haut
- Queue en point d'interrogation (?)
- Petites étincelles au-dessus de la tête
- Expression concentrée
- Noisette magique qui brille
```

### 5. ENCOURAGING (Encourageant) 💪
**Utilisation** : Motivation après échec
```
- Poing levé (posture de super-héros)
- Clin d'œil ou sourire confiant
- Queue dressée fièrement
- Aura d'énergie orange
- Noisette en main tendue (vers l'utilisateur)
```

### 6. SLEEPING (Endormi) 😴
**Utilisation** : Utilisateur inactif depuis longtemps
```
- Yeux fermés avec cils
- "Z Z Z" au-dessus
- Couché sur pile de noisettes/livres
- Queue comme couverture
- Couleurs apaisées
- Respiration visible (animation)
```

## 🎬 ANIMATIONS

### Animations de Base

**IDLE (Au repos)**
```
Loop infini :
1. Léger mouvement de haut en bas (respiration)
2. Queue qui bouge doucement
3. Grignote occasionnellement la noisette
4. Cligne des yeux toutes les 3 secondes
Duration : 2-3 secondes par cycle
```

**WAVE (Salut)**
```
1. Lever une patte
2. Mouvement de gauche à droite (3-4 fois)
3. Grand sourire
4. Queue oscille en rythme
Duration : 1 seconde
Répétitions : 2
```

**CELEBRATION (Célébration)**
```
1. Saut en l'air
2. Rotation 360° (backflip)
3. Étincelles dorées qui explosent
4. Atterrissage avec pose victorieuse
5. Noisettes qui volent autour
Duration : 0.8 secondes
Répétitions : 3
Particules : 6-8 étincelles + 3-4 noisettes
```

**JUMP (Saut)**
```
1. Accroupissement (anticipation)
2. Saut vertical (30px)
3. Retombée légère (bounce)
4. Queue suit le mouvement avec délai
Duration : 0.6 secondes
Répétitions : 2
```

**SLEEP (Sommeil)**
```
Loop infini :
1. Respiration lente (scaling)
2. "Z" apparaissent séquentiellement
3. Léger ronflement (shake)
4. Queue se soulève/baisse doucement
Duration : 2 secondes par cycle
```

**THINK (Réflexion)**
```
Loop infini :
1. Tête penche à gauche
2. Tête penche à droite
3. Petites étincelles apparaissent au-dessus
4. Noisette tourne dans les mains
Duration : 1.5 secondes par cycle
```

**SHOWCASE (Présentation accessoire)**
```
1. Rotation 360° lente
2. Zoom avant (scale 1.15)
3. Accessoire brille/scintille
4. Pose fière finale
Duration : 1.5 secondes
One-shot (pas de répétition)
```

**EVOLUTION (Évolution de niveau)**
```
1. Aura d'énergie entoure Spark
2. Scale up progressif (1 → 1.5)
3. Flash blanc (opacity pulse)
4. Transformation (changement de taille/détails)
5. Explosion d'étincelles
6. Scale down vers nouvelle taille (1.2 final)
Duration : 2 secondes
One-shot
Particules : 12-15 étincelles dorées
```

**COLLECT (Collecte noisette)**
```
1. Noisette tombe du haut
2. Spark suit du regard (head tracking)
3. Attrape la noisette
4. Sourire satisfait
5. Range dans une pile
Duration : 1 seconde
```

## 🔧 SPÉCIFICATIONS TECHNIQUES

### Formats de Fichiers Requis

**Pour Web (Priorité 1)**
```
- SVG (recommandé) : Scalable, léger
- PNG : 512x512px minimum, fond transparent
- WebP : Version optimisée pour performance
```

**Pour Animations**
```
- Lottie JSON (recommandé) : Animations vector
- Sprite Sheets PNG : 1024x1024, 4x4 frames
- GIF : Pour compatibilité (non recommandé)
```

**Résolutions**
```
Icône : 64x64, 128x128, 256x256, 512x512
Full : 1024x1024 (haute qualité)
Thumbnail : 256x256
```

### Spécifications d'Export

**SVG**
```
- Chemins optimisés (simplifié)
- Texte converti en chemins
- Viewbox : "0 0 512 512"
- Pas de filtres complexes
- Compression SVGO
```

**PNG**
```
- Fond transparent
- Compression : PNG-8 si <256 couleurs, sinon PNG-24
- Pas de métadonnées inutiles
```

**Lottie**
```
- Export depuis After Effects
- FPS : 30 ou 60
- Durée : 1-3 secondes max par animation
- Taille fichier : < 100KB
```

## 📐 GUIDELINES D'UTILISATION

### Taille Minimale
- Ne jamais afficher Spark en dessous de 48x48px
- Taille recommandée : 96x96px à 128x128px

### Espacement
- Marge minimale autour de Spark : 16px
- Pour la bulle de message : 8px entre Spark et la bulle

### Accessibilité
```
- Contraste de texte dans bulles : WCAG AA minimum
- Alt text toujours présent : "Spark - [nom du niveau]"
- Animations réductibles (respect prefers-reduced-motion)
- Pas d'animations clignotantes rapides (épilepsie)
```

### Responsive
```
Mobile (< 768px) :
  - Taille Spark : 64px-80px
  - Position : bottom-right, marge 12px
  - Bulle : max-width 250px

Tablet (768px - 1024px) :
  - Taille Spark : 96px-112px
  - Position : bottom-right, marge 16px
  - Bulle : max-width 300px

Desktop (> 1024px) :
  - Taille Spark : 112px-128px
  - Position : bottom-right, marge 24px
  - Bulle : max-width 350px
```

### Contextes d'Utilisation

**À FAIRE ✅**
- Dashboard principal (permanent)
- Fin de quiz (temporaire avec message)
- Achievements débloqués
- Page de profil/paramètres
- Notifications importantes

**À ÉVITER ❌**
- Pendant la saisie de texte (distraction)
- Sur les pages de login/signup
- Dans les modales critiques
- Pendant les examens/quiz (sauf fin)

## 🚀 NOTES FINALES

Spark n'est pas juste une mascotte décorative. C'est un **compagnon d'apprentissage** qui :
- Motive par sa présence
- Récompense les efforts
- Réconforte dans l'échec
- Célèbre les victoires
- Crée un lien émotionnel avec l'application

**L'objectif** : Que les utilisateurs se sentent accompagnés, encouragés, et qu'ils aient envie de faire plaisir à Spark en étudiant régulièrement.

**Le succès sera mesuré par** :
- Taux d'engagement (interactions avec Spark)
- Rétention utilisateurs
- Mentions de Spark dans les retours utilisateurs
- Taux de retour après inactivité (grâce aux messages de Spark)
